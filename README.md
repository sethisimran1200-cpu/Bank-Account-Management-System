# Bank Account Management System

This is my Java OOP assignment. It is a simple bank account management program created using classes and objects.

### Features
- Create bank accounts
- Deposit money
- Withdraw money
- Check account balance
- Display account details

### Files
- `BankAccount.java` – Contains the bank account class and methods.
- `Main.java` – Contains the main method to run the program.
